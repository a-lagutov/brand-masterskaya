## Результат

1. Использовать общий редактор с кнопками оформления в текстах бота; предлагать переменные только из доступного контекста.
2. Добавлять ручные заказы из CSV / TSV или вставленной таблицы после проверки всех строк; откатывать пачку при ошибке и не создавать дубликаты при повторе запроса.
3. Выбирать участников и заказы через таблицы с чекбоксами, поиском и групповым выбором по фильтрам на всех страницах.
4. Показывать автоматическую паузу рассылки только при действующем ограничении Telegram.

## Результаты проверки процесса

На Node.js 22.20.0 прошли корневые `npm run check`, `npm run build`, проверка синтаксиса всех PHP-файлов, `admin typecheck` и все 36 тестов. Тесты используют временную базу и фиктивные данные; бот отключён.

Первый запуск сборки админки в отдельном worktree остановился на внешней символической ссылке `node_modules`: Turbopack требует зависимости внутри своего корня. Это ограничение окружения устранено: зависимости размещены внутри worktree через жёсткие ссылки. Повторная стандартная сборка админки на Node.js 22.20.0 прошла с временной SQLite-базой, отключённым ботом и без live Telegram credentials.

Проверены изменения обработчиков импорта, фильтров, сохранения текста, общих компонентов и сгенерированных файлов. Импорт защищён авторизацией, проверяет строки до записи, использует отдельную транзакцию и повторяемые идентификаторы. Проверки отката и повтора прошли. Реальные Telegram-сообщения, платежи и удалённые заказы не затрагивались. `git diff --check` прошёл. Push, PR и деплой этой задачи не выполнялись.
